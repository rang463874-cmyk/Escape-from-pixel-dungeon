셰터드 픽셀 던전 기반 하드코어 파밍·생존 모드입니다.

**설치 방법 (안드로이드 5.0 이상)**
1. 아래 Assets에서 `EscapeFromPixelDungeon-<버전>.apk`를 휴대폰으로 받습니다.
2. 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용한 뒤 설치합니다.
3. `-devtools.apk`는 개발자 도구가 켜진 테스트용입니다. 별도 앱(이름 뒤 INDEV)으로 설치되고 세이브도 따로입니다.

**0.15.1 새 내용**
- 오픈월드: 요그의 부적을 들고 올라가는 동안에는 마을로 가는 지름길(층 계단의 "마을로 돌아가기", 도시 성문, 귀환 부적)이 막힙니다

**0.15.0 내용**
- 오픈월드: 거점의 **현상금 게시판**에서 도시 구역의 표적 의뢰를 받아 사냥(처치 시 골드 보상)
- 오픈월드: 지역 지도에서 키카드로 **연구소** 입장, 탈출하면 마을로 귀환하며 엔딩
- 오픈월드에서도 연구소 키카드가 나옴

**0.14.1 내용**
- 창고가 정렬될 때 같은 아이템 묶음이 자동으로 하나로 합쳐집니다

**0.14.0 내용**
- 오픈월드 마을: 상점가(희귀 상품, 수상한 상자)와 훈련장(골드로 능력치 숙련 경험치) 추가
- 마을 구매·건설·훈련에 창고 골드도 함께 사용
- 창고에서 아이템·골드를 원하는 개수만큼 꺼내기
- 마을 연금술 작업대에서 창고 재료를 바로 사용

**0.13.0 내용**
- 오픈월드: 요그 드제바를 쓰러뜨리면 거점 마을에 **반지 현자**가 나타납니다. 반지를 바치면 그 효과를 영구히 얻습니다(종류마다 하나, 더 강한 반지로 교체 가능).

**0.12.0 내용**
- 새 모드 **연구소 (최종 목적지)**: 창고의 연구소 키카드를 써서 들어가는 엔드 콘텐츠. 정예 용병·경비 골렘, 허기 2배와 독가스, 발전기 3대와 비상 레버, 레버를 당기면 경보와 정예 증원군. 탈출하면 엔딩.
- 연구소 키카드: 후반 보스, 현상금 표적, 도시 비밀 금고와 보물상자에서 드물게 나옴

**0.11.0 내용**
- 새 모드 **현상금 토벌(HVT)**: 시가전 도시의 구역마다 숨은 표적과 호위병을 사냥합니다. 위치 힌트만 주어지고, 표적은 엄폐·광역 공격·연막 도주·회복 같은 전술로 싸웁니다.
- 표적 처치 시 인식표와 전용 장비 또는 비밀 금고 열쇠를 얻고, 구역 전체가 경보 상태가 되어 탈출이 어려워집니다.

**0.10.0 내용**
