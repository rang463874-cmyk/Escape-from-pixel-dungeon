**설치 방법 (안드로이드 5.0 이상)**
1. 아래 Assets에서 `EscapeFromPixelDungeon-<버전>.apk`를 휴대폰으로 받습니다.
2. 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용한 뒤 설치합니다.
3. `-devtools.apk`는 개발자 도구가 켜진 테스트용입니다. 별도 앱(이름 뒤 INDEV)으로 설치되고 세이브도 따로입니다.
