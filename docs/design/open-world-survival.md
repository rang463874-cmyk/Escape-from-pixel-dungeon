# 오픈월드 생존 모드 기획서

> 상태: 1단계 구현됨, 2단계 이후 설계 단계 · 대상 버전: Escape from Pixel Dungeon (SPD v4.0.2 기반)

## 1. 한 줄 요약

지상의 **거점**을 중심으로 여러 **지역**을 오가며 파밍하고, 몸을 쓰며 **영구적으로 강해지는** 생존 모드입니다. 죽어도 캐릭터와 거점은 남지만, 들고 있던 물건은 죽은 자리에 떨어집니다.

## 2. 확정된 방향

| 항목 | 결정 |
|---|---|
| 월드 구조 | 거점 + 지역 맵. 지역은 저장되고, 시간이 지나면 몬스터와 자원이 다시 생깁니다. |
| 영구 스탯 | 사용할수록 성장하는 방식 + 영구 강화 물약 제작, 두 가지를 섞습니다. |
| 사망 | 소지품은 죽은 자리에 유품으로 남고, 스탯과 거점은 유지됩니다. |
| 생존 요소 | 기존의 허기·무게·부상·출혈에 **갈증**, **낮·밤 주기**, **거점 건설·강화**를 추가합니다. |
| 엔딩 | 앰뮬렛을 가져오면 **생존 성공**을 기록하고, 게임은 계속 이어집니다. |
| 영웅 레벨 | **상한 없음.** |
| 영구 스탯 범위 | 영구 스탯은 **오픈월드 모드에서만** 오르고 적용됩니다. |
| 식별 | 한 번 감정한 물약·주문서는 계속 알고 있습니다. |
| 모드 간 아이템 | 두 모드에서 얻은 아이템을 **서로 가져가서 쓸 수 있습니다**(공용 창고). |

## 3. 익스트랙션 모드와의 관계

- 영웅 선택 화면에서 **모드**를 고릅니다: `익스트랙션` / `오픈월드 생존`.
- 두 모드는 **게임 세이브를 따로** 쓰지만, **창고는 공용**입니다. 익스트랙션에서 탈출해 보관한 아이템을 오픈월드 거점 창고에서 꺼낼 수 있고, 반대도 됩니다.
  - 오픈월드 거점 창고 = 익스트랙션 창고(`stash.dat`)와 같은 저장소
  - 익스트랙션 규칙(시작 장비·가방은 보관 불가)은 공용 창고에도 똑같이 적용합니다.
- **영구 강화 물약**은 오픈월드에서만 마실 수 있습니다. 익스트랙션으로 가져가면 보관·판매만 할 수 있습니다.
- 무게, 부상·출혈, 의료품, 은신처의 상점·연금술 기능은 두 모드가 같은 코드를 씁니다.
- 오픈월드 세이브 하나 = 캐릭터 하나 + 월드 하나입니다.

## 4. 월드 구조

### 4.1 거점 (마을)

- 지상에 있는 안전 지역입니다. 적이 나오지 않습니다(낮·밤과 방벽 규칙은 7장 참고).
- 처음에는 빈 터와 **기본 창고**, **지도 게시판**만 있습니다. 나머지 시설은 건설해야 합니다(8장).
- 부활 지점입니다.

### 4.2 지역

원작의 5개 구역을 지역으로 씁니다. 각 지역은 여러 개의 **구역(층)** 으로 이루어집니다.

| 지역 | 원작 층 | 해금 조건 | 특산 재료 (예시) |
|---|---|---|---|
| 하수도 | 1–4 | 처음부터 | 천 조각, 약초 |
| 감옥 | 6–9 | 하수도 보스 처치 | 고철, 쇠사슬 |
| 동굴 | 11–14 | 감옥 보스 처치 | 광석(암흑 금), 돌 |
| 도시 | 16–19 | 동굴 보스 처치 | 정제 금속, 마력 결정 |
| 지옥 | 21–24 | 도시 보스 처치 | 악마의 정수 |

- 지옥 보스를 잡은 뒤 마지막 층(26층)의 앰뮬렛을 거점으로 가져오면 **생존 성공**이 기록됩니다(날짜, 걸린 일수, 영웅 레벨). 게임은 끝나지 않고 계속됩니다.
- 보스 층(5·10·15·20·25)은 지역의 가장 깊은 곳입니다. 보스는 처음 한 번만 다음 지역을 해금하고, 이후에는 일정 기간마다 다시 나옵니다(희귀 재료 획득처).
- **이동**: 거점의 지도 게시판에서 지역을 고르면 그 지역의 첫 구역으로 갑니다. 지역 안에서는 원작처럼 계단으로 오르내립니다. 구역의 첫 층 올라가는 계단이 거점으로 돌아가는 길입니다.
- **빠른 귀환**: 귀환 주문서(새 아이템, 제작 가능)로 어디서든 거점으로 돌아올 수 있습니다.

### 4.3 지역 재생성

- 각 구역은 **마지막 방문 시각**을 기억합니다.
- 다시 들어갈 때 일정 시간(기본 **3일**, 6장의 하루 기준)이 지났으면 구역을 새로 만듭니다. 지형, 몬스터, 바닥 아이템이 모두 바뀝니다.
- 예외: **유품 가방이 있는 구역**은 가방을 회수할 때까지 재생성하지 않습니다.
- 3일이 지나지 않았으면 그대로 두되, 시간에 비례해 몬스터가 조금씩 다시 생깁니다(원작의 리스폰 규칙 활용).

## 5. 영구 스탯

원작의 영웅 레벨·특성(탤런트)은 그대로 두고, 그 위에 **영구 스탯**을 더합니다. 영구 스탯은 죽어도 유지됩니다.

### 5.1 스탯 종류

| 스탯 | 효과 | 사용 성장 조건 |
|---|---|---|
| 근력 | 힘 +1 (무게 한도도 함께 증가) | 근접 공격을 맞히기, 짐이 무거운 상태로 이동 |
| 체력 | 최대 체력 +3 | 피해를 입고 살아남기 |
| 민첩 | 회피 +5% | 적의 공격을 회피하기 |
| 숙련 | 명중 +5% | 공격을 맞히기 (원거리 포함) |
| 지구력 | 허기·갈증 소모 -5% | 걷기, 오래 활동하기 |
| 회복력 | 자연 회복 +10%, 부상 확률 -5% | 부상·출혈을 치료하기 |

### 5.2 사용 성장

- 각 스탯은 **숙련도 경험치**를 따로 쌓습니다. 일정량이 차면 스탯이 1단계 오릅니다.
- 다음 단계까지 필요한 양은 단계마다 늘어납니다(예: `100 × 1.5^단계`).
- 사용 성장으로 올릴 수 있는 단계는 스탯마다 **최대 5단계**입니다.
- 영구 스탯은 오픈월드 캐릭터에만 저장되고, 익스트랙션 모드에서는 오르지도 적용되지도 않습니다.
- 같은 행동만 반복하는 꼼수를 막기 위해, 자기보다 훨씬 약한 적(영웅 레벨보다 낮은 최대 레벨을 가진 적)에게서는 숙련도가 거의 오르지 않습니다.

### 5.3 영구 강화 물약

- 거점의 **연금술 제작대**에서 지역 특산 재료와 보스 재료로 제작합니다.
- 스탯마다 물약이 하나씩 있습니다(근력의 강장제, 체력의 강장제 …).
- 물약으로 올릴 수 있는 단계는 스탯마다 **최대 5단계**입니다. 사용 성장과 합쳐 스탯당 최대 10단계입니다.
- 단계가 오를수록 더 깊은 지역의 재료가 필요합니다. 1–2단계는 하수도·감옥, 5단계는 지옥 보스 재료가 필요합니다.

### 5.4 화면

- 영웅 정보창에 **스탯 탭**을 추가합니다. 스탯마다 현재 단계(사용 / 물약)와 다음 단계까지의 진행도를 보여 줍니다.
- 단계가 오르면 로그와 효과음으로 알립니다.

## 6. 시간과 낮·밤

- 월드 시계는 원작의 전역 턴 카운터를 씁니다. **하루 = 1200턴**: 낮 800턴, 밤 400턴입니다.
- 화면 구석에 현재 날짜와 시간대(낮/저녁/밤)를 표시합니다.

| 항목 | 낮 | 밤 |
|---|---|---|
| 시야 | 기본 | -40% (빛 효과로 상쇄 가능) |
| 몬스터 리스폰 | 기본 | 2배 |
| 강화(챔피언) 몬스터 확률 | 기본 | 2배 |
| 야간 전용 | — | 밤에만 피는 약초, 밤에만 나오는 적 |

- 횃불의 가치가 올라갑니다. 횃불과 랜턴은 거점에서 제작할 수 있습니다.

## 7. 생존 요소

### 7.1 갈증 (신규)

- 허기와 같은 방식의 수치이고, 허기보다 **약 2배 빨리** 줄어듭니다.
- 단계: 목마름 → 탈수(최대 체력의 일부씩 피해, 회피 감소).
- **물 얻기**
  - 수통(새 아이템, 물 5회분): 거점 우물에서 채웁니다.
  - 던전의 물 타일에서 직접 마시거나 수통을 채울 수 있습니다. 하지만 **생수**라서 일정 확률로 배탈(구역질: 일정 시간 허기·갈증 회복 불가)이 납니다.
  - 모닥불에서 끓이면 깨끗한 물이 됩니다.
- 원작의 이슬 수통(체력 회복)은 그대로 둡니다.

### 7.2 기존 요소와의 연결

- **허기**: 원작 그대로입니다. 거점의 작물밭과 조리대에서 식량을 마련할 수 있습니다.
- **무게**: 그대로입니다. 근력 스탯이 오르면 무게 한도도 함께 오릅니다.
- **부상·출혈**: 그대로입니다. 거점의 의무실에서 골드로 치료할 수 있습니다.

## 8. 거점 건설·강화

### 8.1 방식

- 거점에는 정해진 **건설 부지**가 있습니다. 부지를 누르면 지을 수 있는 시설 목록이 뜹니다.
- 시설마다 1–3단계가 있고, 재료와 골드로 짓고 강화합니다.

### 8.2 시설

| 시설 | 효과 | 단계별 강화 |
|---|---|---|
| 창고 | 거점 보관함 | 보관 칸 수 증가 |
| 침대 | 잠자기(시간 넘기기, 체력·피로 회복), 부활 위치 | 회복량 증가 |
| 우물 | 깨끗한 물 무한 | 수통 2배 빨리 채우기 |
| 모닥불·조리대 | 물 끓이기, 고기 굽기, 요리 | 요리 종류 추가 |
| 연금술 제작대 | 원작 연금술 + 영구 강화 물약 | 재료 소모량 감소 |
| 대장간 | 장비 수리·재련 | 강화 성공 보너스 |
| 의무실 | 골드로 부상·출혈 치료 | 비용 감소 |
| 작물밭 | 씨앗을 심어 며칠 뒤 수확 | 칸 수 증가 |
| 방벽 | 밤의 습격 방어 | 방어력 증가 |

### 8.3 재료

가능하면 원작 아이템을 재료로 씁니다(고철 조각, 암흑 금, 구의 점액, 씨앗, 룬석). 부족한 것만 새로 추가합니다.

| 새 재료 | 주로 얻는 곳 |
|---|---|
| 천 조각 | 하수도, 도적류 적 |
| 목재 | 하수도·감옥의 상자와 가구 |
| 돌 블록 | 동굴 |
| 정제 금속 | 도시, 대장간에서 고철 정제 |
| 보스 정수 | 각 지역 보스 (지역마다 1종) |

### 8.4 밤의 습격 (선택 요소, 후순위)

- 며칠에 한 번, 밤에 적이 거점을 습격합니다. 방벽이 없거나 약하면 시설 하나가 손상됩니다.
- 처음 구현에서는 빼고, 기본 루프가 재미있는지 확인한 뒤 넣는 것을 권장합니다.

## 9. 사망과 유품

- 죽으면 **들고 있던 모든 것**(장착 장비, 가방, 골드)이 **유품 가방**에 담겨 죽은 자리에 남습니다.
- 영웅은 거점의 침대(없으면 거점 입구)에서 부활합니다. 체력은 50%, 허기·갈증은 절반, 부상과 출혈은 치료된 상태입니다.
- 유품 가방은 **하나만** 존재합니다. 회수하기 전에 또 죽으면 이전 가방은 사라집니다.
- 지도 게시판에 유품 가방이 있는 지역과 구역이 표시됩니다.
- 영구 스탯, 거점 시설, 거점 창고는 그대로 남습니다.

## 10. 핵심 플레이 흐름

```
거점에서 준비 (창고·제작·식량·물)
      │
      ▼
지도 게시판에서 지역 선택 ──► 구역 탐험·파밍 (갈증·허기·무게·부상 관리, 밤 조심)
      ▲                                │
      │                     ┌──────────┴──────────┐
      │                  귀환                  사망
      │                     │                     │
      └── 판매·제작·건설 ◄──┘        거점 부활 → 유품 회수하러 출발
           영구 강화 물약
```

## 11. 엔진 구현 방안 (SPD 기준)

| 기능 | 구현 방안 |
|---|---|
| 모드와 세이브 | 영웅 선택 화면에 모드 토글을 추가하고, 오픈월드는 별도 세이브 슬롯 범위를 씁니다. |
| 거점 레벨 | 새 `BaseLevel` 클래스. 원작은 층을 (깊이, 분기)마다 파일로 저장하는데 분기 2 이상이 비어 있으므로, 거점을 **분기 2**에 둡니다. |
| 지역 | 원작 분기 0의 층 생성을 그대로 씁니다. 지도 이동은 `InterlevelScene`에 목적지 깊이·분기를 넘기는 방식입니다. |
| 재생성 | 구역별 마지막 방문 시각을 저장하고, 기준 시간이 지났으면 저장된 층 파일을 버리고 새로 생성합니다. |
| 월드 시계 | 원작의 전역 턴 카운터(`Statistics.duration`)로 날짜와 시간대를 계산합니다. |
| 낮·밤 | 시야는 무게·부상과 같은 위치(`Level.updateFieldOfView`)에 곱셈 훅을 겁니다. 리스폰은 `Level.respawnCooldown`에 훅을 겁니다. |
| 갈증 | 원작 허기(`Hunger`)를 본뜬 새 버프입니다. |
| 영구 스탯 | 캐릭터 데이터에 스탯 단계·숙련도를 저장합니다. 효과는 무게·부상과 같은 위치(`Hero.speed`, `attackSkill`, `defenseSkill`, `Regeneration` 등)에 훅을 겁니다. |
| 사망·부활 | `Hero.die`를 가로채 게임오버 대신 유품 가방 생성 → 거점으로 이동시킵니다. |
| 거점 시설 | 거점 레벨에 상호작용 가능한 시설 오브젝트를 두고, 은신처 메뉴처럼 창을 띄웁니다. |

### 구현 위험 요소

- 원작은 "한 번 내려가면 끝나는 게임"을 전제로 만든 곳이 많습니다(점수, 랭킹, 배지, 퀘스트 NPC). 반복 방문과 재생성 시 퀘스트 NPC가 다시 나오거나 사라지는 문제를 점검해야 합니다.
- 보스 층은 전투 상태를 층 파일에 저장합니다. 보스 재등장은 층을 새로 만드는 방식으로 처리하는 것이 안전합니다.
- 사망을 가로채는 부분은 원작의 앙크(부활) 처리와 충돌하지 않게 해야 합니다.

## 12. 구현 단계

각 단계가 끝날 때마다 플레이할 수 있는 상태를 목표로 합니다.

| 단계 | 내용 | 끝나면 할 수 있는 것 |
|---|---|---|
| 1 ✅ | 모드 선택, 별도 세이브, 거점 레벨(빈 마을 + 창고), 지도 게시판 이동, 사망 시 거점 부활과 유품 가방 | 거점과 하수도를 오가며 파밍하고, 죽으면 유품 회수 |
| 2 ✅ | 영구 스탯(사용 성장 + 강화 물약), 스탯 탭 | 플레이할수록 강해짐 |
| 3 ✅ | 갈증, 수통, 우물, 생수 배탈 | 물 관리 |
| 4 | 낮·밤 주기, 시계 표시 | 시간대에 따라 다른 플레이 |
| 5 | 거점 건설·강화, 새 재료 | 거점 꾸미기와 장기 목표 |
| 6 | 지역 재생성, 보스 재등장, 지역 해금, 밸런스 | 전체 루프 완성 |
| 7 (선택) | 밤의 습격 | 거점 방어 |

## 12-1. 1단계 구현 메모

- 지도 게시판은 마을의 **던전 입구 계단**입니다. 계단을 밟으면 지역 지도가 열리고, 마을에 도착할 때도 이 계단 위에 섭니다.
- 거점 관리인 한 명이 창고·거래·연금술·지도를 모두 맡습니다. 시설 건설(5단계)이 들어오면 시설별로 나눌 예정입니다.
- 마을은 원작에서 쓰지 않는 분기 2번에 저장됩니다(`efpd/BaseLevel.java`).
- 유품은 원작의 유골 더미 모양으로 놓이고, 열면 가방이 나옵니다. 가방을 주우면 장비가 가방으로 돌아옵니다(다시 장착해야 함).
- 사망 후 부활 시 버프가 초기화되어 부상·출혈·허기가 모두 풀립니다(기획의 "허기 절반"은 단순화).
- 지역 첫 층(6·11·16·21층)의 올라가는 계단은 "마을로 돌아가기 / 위층으로 올라가기"를 고르게 합니다.
- 익스트랙션의 보스 층 탈출과 은신처는 오픈월드에서 꺼져 있습니다.

## 12-2. 2단계 구현 메모

- 데이터는 런의 `Statistics` 번들에 함께 저장됩니다(`efpd/PermStats.java`). 오픈월드 세이브마다 따로 있고, 익스트랙션에서는 오르지도 적용되지도 않습니다. 1단계 세이브는 모두 0으로 불러옵니다.
- 숙련도 경험치(행동당): 근접 적중 3, 과적 상태 걸음 0.4(근력) / 최대 체력만큼 피해 40(체력, 허기 피해 제외) / 회피 3(민첩) / 적중 2(숙련) / 걸음 0.15(지구력, 마을 안 제외) / 치료 1회 15(회복력, 의료품 또는 부상·출혈을 고친 치유 물약).
- 필요량은 `100 × 1.5^단계`(100, 150, 225, 338, 506)입니다. 영웅 레벨보다 최대 레벨이 낮은 적에게서는 10%만 얻습니다.
- 영구 강화 물약은 **강장제**(`efpd/items/Tonic.java`)입니다. 재료는 5단계의 재료 체계 대신 2단계용 **지역 정수**(`efpd/items/Essence.java`)를 먼저 넣었습니다.
  - 정수: 오픈월드에서 적이 10% 확률로 그 지역의 정수 1개, 보스는 4개를 떨어뜨립니다.
  - 레시피: 씨앗 1 + 같은 지역 정수 2(연금술 칸 3개). 에너지 `2 + 2×등급`.
  - 등급 = 정수의 지역(하수도 1 … 지옥 5). 물약 단계 N으로 올리려면 N등급 이상이 필요합니다. 그래서 기획대로 1단계는 하수도, 5단계는 지옥 재료가 필요합니다.
  - 익스트랙션에서도 만들고 창고로 옮길 수 있지만, 마시는 것은 오픈월드에서만 됩니다.
- 부상 확률 감소는 "부상이 생길 때 회복력 단계×5% 확률로 막기"로 구현했습니다.
- 5단계에서 재료 체계가 들어오면 정수를 그 체계로 옮기거나 그대로 하나의 재료로 둘 예정입니다.

## 12-3. 3단계 구현 메모

- 갈증은 오픈월드에서만 붙는 영웅 버프입니다(`efpd/Thirst.java`). 턴마다 1씩 오르고(지구력 스탯으로 감소), 150에서 목마름, 250에서 탈수입니다. 보스 방에 갇혔을 때는 허기처럼 멈춥니다.
- 탈수: 턴마다 최대 체력의 1/700 피해(굶주림은 1/1000), 자연 회복 정지, 회피 ×0.75. 탈수로 죽으면 오픈월드 사망 처리(유품·마을 부활)를 똑같이 따릅니다.
- 수통(`efpd/items/Canteen.java`): 5모금, 한 모금에 갈증 -150. 행동은 마신다, 채운다, 물을 떠 마신다(물가에서 바로), 끓인다(마을에서 생수일 때)입니다.
- 물가 판정: 영웅 칸과 주변 8칸에 우물이 있으면 깨끗한 물, 물 타일이 있으면 생수입니다. 단, 마을의 물(샘)은 깨끗한 물입니다. 1단계 세이브의 마을에는 우물이 없지만 샘을 쓸 수 있습니다.
- 생수는 한 모금마다 30% 확률로 배탈(`efpd/Nausea.java`, 100턴)을 일으킵니다. 배탈 중에는 먹기와 마시기가 거부되고, 음식과 물은 사라지지 않습니다.
- 기획의 "모닥불에서 끓이기"는 모닥불(거점 시설, 5단계)이 아직 없어서 **마을 어디서나 끓이기**로 대신했습니다. 5단계에서 모닥불로 옮길 예정입니다.
- 새로 시작한 오픈월드 게임은 시작 장비에 수통이 들어 있어 창고에 맡길 수 없습니다. 예전 세이브는 거점 관리인에게서 사면 됩니다.

## 13. 결정 사항 (기존 미정 항목)

1. **엔딩**: 생존 성공만 기록하고 계속 플레이합니다.
2. **영웅 레벨**: 상한을 없앱니다. 원작은 30레벨까지 경험치 표와 특성 포인트가 정해져 있으므로, 30레벨 이후에는 레벨마다 최대 체력만 오르고 특성 포인트는 주지 않는 것을 기본안으로 합니다.
3. **식별**: 유지합니다. 오픈월드 월드는 하나의 게임이 계속되므로 원작 구조로도 자연스럽게 유지됩니다.
4. **모드 간 아이템**: 공용 창고로 서로 가져가서 씁니다. 감정 상태는 모드마다 따로라서, 다른 모드에서 가져온 물약·주문서는 창고에 넣을 때 감정된 상태로 보관하고 꺼낼 때 감정 처리합니다(익스트랙션 창고의 현재 방식과 같음).
5. **수치**: 하루 길이, 재생성 주기, 스탯 단계별 요구치 등은 1–2단계 구현 후 실제 플레이로 조정합니다.
