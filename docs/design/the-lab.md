# 연구소 (The Lab) 설계: 최종 목적지

Escape from Pixel Dungeon의 마지막 목표입니다. 다른 모드에서 장비와 **연구소 키카드**를 모아 연구소에 들어가고, 살아서 나오면 엔딩입니다(`efpd/lab/`).

## 1. 입장

- 모드 선택의 다섯 번째 항목. 창고에 키카드가 없으면 얻는 방법을 알려주고 시작하지 않습니다. 있으면 1장을 쓰고 시작합니다.
- 모드 선택 창에 창고의 키카드 수와 연구소 탈출 횟수가 표시됩니다(`stash.dat`의 `lab_clears`).
- 영웅은 12레벨로 시작합니다. 시작 방(시작 지점 4칸 이내)에서는 발전기를 켜기 전까지 창고에서 물건을 꺼낼 수 있습니다.

## 2. 키카드 (`Keycard`)

익스트랙션 계열 모드(익스트랙션, 시가전, 현상금 토벌)에서만 나옵니다. 오픈월드, 일일 도전, 연구소 안에서는 나오지 않습니다.

| 출처 | 확률 |
|---|---|
| DM-300 (15층) | 20% |
| 드워프 왕 (20층) | 40% |
| 요그 드제바 (25층) | 100% |
| 현상금 표적 | 10% × 구역 번호 |
| 도시 비밀 금고 | 35% |
| 3구역부터 건물 맨 위층 보물상자의 희귀 전리품 | 4% |

## 3. 맵 (`LabLevel`)

- 64×64, 4×4 격자의 방(8–13칸)을 무작위 신장 트리와 고리 통로로 연결
- 시작: 왼쪽 위 방. 탈출 엘리베이터와 비상 레버: 오른쪽 아래 방
- 발전기 3대: 오른쪽 위, 왼쪽 아래, 가운데 방 중 하나. 발전기마다 경비 1명
- 가스 배출구 10개(시작 방 근처 제외), 방 구석의 연구 장비
- 전리품: 방의 60%에 1개(1/3은 희귀), 잠긴 보물상자 3개(희귀), 의료품·탄약·음식
- 희귀 전리품(`LabLoot.rare`): +1~2 총기, 5등급 강장제, 강화 주문서 1–2, 힘의 물약, +1~2 반지·마법봉(또는 아티팩트), +1~2 갑옷

## 4. 적과 환경

- 정예 용병(체력 55, 사거리 7 사격, 방어 2–9)과 경비 골렘(체력 85, 피해 12–20)만 나옵니다. 30%는 챔피언 특성.
- 동시 최대 12마리(+발전기 경비), 시작 방 근처에는 다시 나타나지 않습니다.
- 허기 2배
- 12턴(±20%)마다 영웅에게서 2–10칸 떨어진 가스 배출구 하나에서 독가스

## 5. 탈출 절차

1. 발전기에 올라서면 켜집니다. 켤 때마다 14칸 안의 적이 모여들고 정예 2명이 나타납니다.
2. 세 대가 모두 돌아가면 비상 레버를 당길 수 있습니다.
3. 레버를 당기면 경보, 화면 흔들림, 보스 음악. 정예 7명 중 절반은 엘리베이터 근처, 절반은 영웅 주변에 나타납니다. 영웅에게 **봉쇄** 상태가 붙어 8턴마다 모든 적이 위치를 알게 됩니다.
4. 엘리베이터에 올라서면 탈출합니다: 은신처 메뉴로 가고, 전리품이 창고로 옮겨지며, **최종 목적지** 엔딩 창과 함께 탈출 횟수가 1 늘어납니다.

## 6. 조정값

`Lab`(`START_LEVEL`, `GENERATORS`, `HUNGER_MULTI`, `GAS_INTERVAL`, `GEN_REINFORCE`, `LEVER_REINFORCE`), `Keycard`(드랍 확률), `LabMobs`(용병 비율, 챔피언 확률), `LabMercenary`·`LabGolem`(능력치) 맨 위에 있습니다.
