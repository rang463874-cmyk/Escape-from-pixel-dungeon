# Escape from Pixel Dungeon

[Shattered Pixel Dungeon](https://github.com/00-Evan/shattered-pixel-dungeon) (v4.0.2)을 기반으로 한 **하드코어 파밍·익스트랙션 생존 모드**입니다.
원작은 Evan Debenham의 작품이며, 이 모드도 원작과 같이 **GPLv3** 라이선스를 따릅니다 (`LICENSE.txt`). 원본 README는 `README_SPD.md`에 있습니다.

## 핵심 루프 (익스트랙션)

- **은신처 창고(Stash)**: 게임과 게임 사이에 유지되는 영구 창고 (`stash.dat`).
- **탈출 지점**
  - 1층 입구 계단
  - 각 보스 층(5·10·15·20·25층)의 위로 올라가는 계단: 보스를 쓰러뜨린 뒤에 열립니다. "탈출하기 / 위층으로 올라가기" 중에서 고를 수 있습니다.
- **탈출하면** 전리품과 골드가 창고로 옮겨지고 게임이 끝납니다.
  - 시작 장비, 가방, 퀘스트 아이템은 저장되지 않습니다. 가방 안에 든 아이템은 저장됩니다.
  - 시작 장비와 같은 아이템을 주워서 겹친 경우에는 주운 수량만 저장됩니다.
  - 시작 장비는 강화해도 시작 장비로 남습니다. 변형 주문서·연금술로 바꾼 결과물은 새 아이템이므로 저장됩니다.

## 무게 기반 인벤토리

- 모든 아이템(장착 중인 것과 가방 안의 것 포함)에 무게가 있습니다. 아이템 설명창, 인벤토리, 영웅 정보창에서 확인할 수 있습니다.
- 최대 무게 = 5 + 힘 × 2 (힘 10이면 25)
- 최대 무게를 넘으면 단계별로 이동 속도와 회피가 떨어지고, 케틀벨 아이콘이 표시됩니다.

| 단계 | 무게 | 이동 속도 | 회피 |
|---|---|---|---|
| 짐이 무거움 | 100% 초과 | -15% | -15% |
| 과적 | 125% 초과 | -33% | -33% |
| 극심한 과적 | 150% 초과 | -50% | -50% |

- 주요 무게: 갑옷 2.5×티어, 근접 무기 1.5×티어, 투척 무기 0.25×티어(개당), 물약 0.4, 주문서 0.1, 완드 0.5, 반지 0.1, 아티팩트 1, 식량 0.5~1, 폭탄 1, 가방 0.5
- 수치는 모두 `efpd/Weight.java` 상단에서 조정할 수 있습니다.
- **사망**: 가지고 들어간 모든 것을 잃습니다.
- **준비**: 창고에서 아이템을 꺼내는 건 탐험 시작 전(처음 내려가기 전)에만 할 수 있습니다.
- 앰뮬렛을 들고 탈출해도 창고에 보관됩니다.

모드 코드는 `core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/efpd/`에 있고, 원본 파일을 고친 곳에는 `//EFPD:` 주석을 달았습니다.

## 부상·출혈

- 적에게 맞으면 적마다 정해진 신체 부위에 부상을 입습니다 (`efpd/InjuryTable.java`).
  - 예: 쥐 → 하체, 뱀 → 발, 놀 → 상체, 박쥐 → 머리·팔, 브루트 → 상체·머리
  - 표에 없는 적은 크기로 추정합니다 (큰 적 → 상체·머리, 나머지 → 상체·팔·하체).
- 발생 조건: 맞을 때마다 6% 확률, 한 번에 최대 체력의 25% 이상 맞으면 확정, 40% 이상이면 바로 중상
- 같은 부위를 다시 다치면 경상 → 중상이 됩니다.

| 부위 | 경상 | 중상 |
|---|---|---|
| 머리 | 명중 -10%, 시야 -25% | 명중 -25%, 시야 -50% |
| 상체 | 자연 회복 -50% | 자연 회복 없음 |
| 팔 | 명중 -10%, 공격력 -15% | 명중 -20%, 공격력 -30% |
| 하체 | 이동 속도 -20% | 이동 속도 -40% |
| 발 | 회피 -20% | 회피 -40% |

- 부상을 입으면 출혈이 생길 수 있습니다 (경상 30%, 중상 70%). 출혈은 저절로 멈추지 않습니다.
  - 출혈: 턴당 최대 체력의 0.5% (자연 회복과 비슷)
  - 과다 출혈: 턴당 최대 체력의 약 1.7%
- 치료 (휴식으로는 낫지 않음)

| 아이템 | 효과 | 층마다 나올 확률 |
|---|---|---|
| 붕대 | 출혈 멈춤 | 1개 확정, 50% 확률로 1개 더 |
| 부목 | 가장 심한 팔다리(팔·하체·발) 1곳 완치 | 40% |
| 응급처치 키트 | 모든 부상 + 출혈 치료 | 15% |
| 치유 물약 | 모든 부상 + 출혈 치료 | (기존 드랍) |

- 정화 물약, 상태이상을 푸는 씨앗·치유 다트 같은 기존 해독 효과로는 부상·출혈이 낫지 않습니다.
- 수치는 `efpd/Injuries.java`, `efpd/Hemorrhage.java`, `efpd/items/MedicalSupplies.java` 상단에서 조정할 수 있습니다.

## 빌드 (데스크톱)

```bash
# Android SDK 없이 데스크톱만 빌드/실행
./gradlew desktop:debug -PdesktopOnly     # 실행
./gradlew desktop:release -PdesktopOnly   # 실행 가능한 jar
```

`-PdesktopOnly`를 빼면 원래처럼 android/ios 모듈도 포함됩니다 (Android SDK 필요).
