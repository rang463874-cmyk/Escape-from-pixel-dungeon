# Escape from Pixel Dungeon

[Shattered Pixel Dungeon](https://github.com/00-Evan/shattered-pixel-dungeon) (v4.0.2)을 기반으로 한 **하드코어 파밍·익스트랙션 생존 모드**입니다.
원작은 Evan Debenham의 작품이며, 이 모드도 원작과 같이 **GPLv3** 라이선스를 따릅니다 (`LICENSE.txt`). 원본 README는 `README_SPD.md`에 있습니다.

## 최종 목적지: 연구소 (The Lab)

이 모드의 마지막 목표는 **연구소를 탈출하는 것**입니다. 익스트랙션·시가전·현상금 토벌에서 장비를 모으고 **연구소 키카드**를 구해 창고에 넣은 뒤, 키카드를 써서 연구소에 들어가 살아서 나오면 엔딩입니다. 자세한 내용은 아래 [연구소 모드](#연구소-모드-최종-목적지)를 보세요.

## 핵심 루프 (익스트랙션)

- **은신처 창고(Stash)**: 게임과 게임 사이에 유지되는 영구 창고 (`stash.dat`).
- **탈출 지점**
  - 1층 입구 계단
  - 각 보스 층(5·10·15·20·25층)의 위로 올라가는 계단: 보스를 쓰러뜨린 뒤에 열립니다. "탈출하기 / 위층으로 올라가기" 중에서 고를 수 있습니다.
  - 상점(6·11·16층, 20층 임프 상점)의 **은신처 길잡이**: 앙크의 두 배 가격. 사는 즉시 그 자리에서 탈출합니다(보관 불가).
- **탈출하면** 전리품과 골드가 창고로 옮겨지고 게임이 끝납니다.
  - 시작 장비, 가방, 퀘스트 아이템은 저장되지 않습니다. 가방 안에 든 아이템은 저장됩니다.
  - 시작 장비와 같은 아이템을 주워서 겹친 경우에는 주운 수량만 저장됩니다.
  - 시작 장비는 강화해도 시작 장비로 남습니다. 변형 주문서·연금술로 바꾼 결과물은 새 아이템이므로 저장됩니다.

## 무게 기반 인벤토리

- 모든 아이템(장착 중인 것과 가방 안의 것 포함)에 무게가 있습니다. 아이템 설명창, 인벤토리, 영웅 정보창에서 확인할 수 있습니다.
- 최대 무게 = 5 + 힘 × 2 (힘 10이면 25)
- 최대 무게를 넘으면 단계별로 이동 속도와 회피가 떨어지고, 케틀벨 아이콘이 표시됩니다.

| 단계 | 무게 | 이동 속도 | 회피 |
|---|---|---|---|
| 짐이 무거움 | 100% 초과 | -15% | -15% |
| 과적 | 125% 초과 | -33% | -33% |
| 극심한 과적 | 150% 초과 | -50% | -50% |

- 주요 무게: 갑옷 2.5×티어, 근접 무기 1.5×티어, 투척 무기 0.25×티어(개당), 물약 0.4, 주문서 0.1, 완드 0.5, 반지 0.1, 아티팩트 1, 식량 0.5~1, 폭탄 1, 가방 0.5
- 수치는 모두 `efpd/Weight.java` 상단에서 조정할 수 있습니다.
- **사망**: 가지고 들어간 모든 것을 잃습니다.
- **준비**: 창고에서 아이템을 꺼내는 건 탐험 시작 전(처음 내려가기 전)에만 할 수 있습니다.
- 앰뮬렛을 들고 탈출해도 창고에 보관됩니다 (이 경우 은신처 메뉴 없이 바로 보관).

## 은신처 (탈출 후)

탈출하면 바로 게임이 끝나지 않고 은신처 메뉴가 뜹니다. 은신처에서는 적이 사라지고 피해를 입지 않습니다.

- **아이템 판매**: 원작 상점과 같은 가격으로 판매. 시작 장비는 팔 수 없습니다 (던전 상점도 동일).
- **물자 구매**: 붕대 40, 부목 100, 응급처치 키트 200, 식량 50, 치유 물약 300 골드 (`efpd/WndHideoutShop.java`에서 조정)
- **연금술 제작대**: 원작 연금술 화면을 그대로 사용합니다.
- **창고**: 창고 아이템을 꺼내서 팔거나 연금술 재료로 쓸 수 있습니다. 꺼낸 아이템은 정리를 끝낼 때 다시 보관됩니다.
- **정리 끝내기**: 남은 아이템, 골드, 연금 에너지를 창고에 보관하고 게임을 끝냅니다.
- 창고의 골드와 연금 에너지는 은신처에 들어올 때 꺼내져서 바로 쓸 수 있습니다.
- 은신처에서 게임을 종료해도, 이어하기를 하면 은신처 메뉴로 돌아옵니다.

모드 코드는 `core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/efpd/`에 있고, 원본 파일을 고친 곳에는 `//EFPD:` 주석을 달았습니다.

## 부상·출혈

- 적에게 맞으면 적마다 정해진 신체 부위에 부상을 입습니다 (`efpd/InjuryTable.java`).
  - 예: 쥐 → 하체, 뱀 → 발, 놀 → 상체, 박쥐 → 머리·팔, 브루트 → 상체·머리
  - 표에 없는 적은 크기로 추정합니다 (큰 적 → 상체·머리, 나머지 → 상체·팔·하체).
- 발생 조건: 맞을 때마다 6% 확률, 한 번에 최대 체력의 15% 이상 맞으면 확정, 30% 이상이면 바로 중상
- 같은 부위를 다시 다치면 경상 → 중상이 됩니다.

| 부위 | 경상 | 중상 |
|---|---|---|
| 머리 | 명중 -10%, 시야 -25% | 명중 -25%, 시야 -50% |
| 상체 | 자연 회복 -50% | 자연 회복 없음 |
| 팔 | 명중 -10%, 공격력 -15% | 명중 -20%, 공격력 -30% |
| 하체 | 이동 속도 -20% | 이동 속도 -40% |
| 발 | 회피 -20% | 회피 -40% |

- 부상을 입으면 출혈이 생길 수 있습니다 (경상 30%, 중상 70%). 출혈은 저절로 멈추지 않습니다.
  - 출혈: 턴당 최대 체력의 0.5% (자연 회복과 비슷)
  - 과다 출혈: 턴당 최대 체력의 약 1.7%
- 치료 (휴식으로는 낫지 않음)

| 아이템 | 효과 | 층마다 나올 확률 |
|---|---|---|
| 붕대 | 출혈 멈춤 | 1개 확정, 50% 확률로 1개 더 |
| 부목 | 가장 심한 팔다리(팔·하체·발) 1곳 완치 | 40% |
| 응급처치 키트 | 모든 부상 + 출혈 치료 | 15% |
| 치유 물약 | 모든 부상 + 출혈 치료 | (기존 드랍) |

- 정화 물약, 상태이상을 푸는 씨앗·치유 다트 같은 기존 해독 효과로는 부상·출혈이 낫지 않습니다.
- **휴식 치료**: 시야에 적이 없을 때 제자리 대기·휴식을 하면 턴마다 낮은 확률로 부상이 한 단계씩 낫습니다(경상 1/150, 중상 → 경상 1/300, 회복력 스탯으로 증가). 출혈 중에는 낫지 않습니다.
- 수치는 `efpd/Injuries.java`, `efpd/Hemorrhage.java`, `efpd/items/MedicalSupplies.java` 상단에서 조정할 수 있습니다.

## 오픈월드 생존 모드 (1–6단계)

영웅 선택 후 **시작**을 누르면 모드를 고릅니다: `익스트랙션` / `오픈월드 생존`.

- **거점 마을**: 오픈월드는 마을에서 시작합니다. 마을은 안전하고, 연금술 솥이 있습니다.
- **거점 관리인**: 지역 지도, 공용 창고(꺼내기·맡기기·골드 맡기기), 판매, 구매, 연금술을 맡습니다.
- **지역 지도**: 마을의 던전 입구 계단을 밟으면 열립니다. 하수도·감옥·동굴·도시·지옥 중 해금된 지역의 첫 층으로 이동합니다. 지역은 앞 지역의 보스를 잡으면 열립니다.
- **귀환**: 지역 첫 층의 올라가는 계단에서 마을로 돌아갈 수 있습니다.
- **사망**: 게임이 끝나지 않습니다. 장착 장비를 포함한 소지품과 골드가 쓰러진 자리에 **유품**으로 남고, 마을에서 체력 절반으로 깨어납니다. 유품은 하나만 존재하고(새로 죽으면 이전 유품은 사라짐), 지역 지도에 위치가 표시됩니다.
- **생존 성공**: 앰뮬렛을 지상으로 가져오면 기록이 남고 게임은 계속됩니다.
- **공용 창고**: 익스트랙션 창고와 같은 저장소입니다. 두 모드에서 얻은 아이템을 서로 가져가 쓸 수 있습니다.
- **영구 스탯**(2단계): 근력·체력·민첩·숙련·지구력·회복력 6가지. 죽어도 유지되고, 오픈월드에서만 오르고 적용됩니다. 영웅 정보창의 네 번째 탭(빨간 물약 아이콘)에서 확인합니다.
  - **단련**: 해당 행동을 하면 숙련도가 쌓여 스탯마다 최대 5단계까지 오릅니다. 근력 = 근접 공격 적중·과적 상태로 걷기, 체력 = 피해를 입고 버티기, 민첩 = 회피, 숙련 = 공격 적중(원거리 포함), 지구력 = 걷기, 회복력 = 부상·출혈 치료. 영웅 레벨보다 최대 레벨이 낮은 약한 적에게서는 10%만 쌓입니다.
  - **강장제**: 적이 가끔 떨어뜨리는(보스는 4개) **지역 정수** 2개와 씨앗 1개를 연금술 솥에 넣으면 강장제가 됩니다. 씨앗이 스탯을 정하고(뱀뿌리 = 근력, 태양초 = 체력, 신속엉겅퀴 = 민첩, 미명초 = 숙련, 눈꽃송이 = 지구력, 마법풀 = 회복력), 정수의 지역이 등급(하수도 1 ~ 지옥 5)을 정합니다. 강장제로 스탯마다 최대 5단계를 더 올리며, N단계에는 N등급 이상의 강장제가 필요합니다.
  - 단계당 효과: 힘 +1(무게 한도도 증가), 최대 체력 +3, 회피 +5%, 명중 +5%, 허기 -5%, 자연 회복 +10%와 부상 확률 -5%. 수치는 `efpd/PermStats.java` 상단에 있습니다.
- **갈증**(3단계): 허기보다 약 2배 빨리 오릅니다. 150턴이면 목마름, 250턴이면 탈수입니다. 탈수 상태에서는 체력이 조금씩 줄고 자연 회복이 멈추며 회피가 25% 떨어집니다. 지구력 스탯은 갈증도 줄여 줍니다.
  - **수통**: 오픈월드는 가득 찬 수통(5모금)을 들고 시작합니다. 한 모금이 갈증 150을 해소합니다. 거점 관리인에게서도 살 수 있습니다(60골드).
  - **물 얻기**: 마을 우물이나 샘 옆에서는 깨끗한 물을 채웁니다. 던전의 물 옆에서는 **생수**를 채우거나 바로 떠 마실 수 있습니다.
  - **생수**: 마실 때마다 30% 확률로 **배탈**이 나서 100턴 동안 먹지도 마시지도 못합니다. 생수를 깨끗한 물에 섞으면 수통 전체가 생수가 됩니다. 마을에서 **끓이면** 깨끗해집니다.
- **낮·밤**(4단계): 하루는 1200턴입니다(낮 0–699, 저녁 700–799, 밤 800–1199). 우측 상단 메뉴 아래에 "N일차 낮/저녁/밤"이 표시되고, 시간대가 바뀌면 로그로 알려 줍니다.
  - 밤에는 던전에서 시야가 40% 줄고(빛 버프가 있으면 그대로), 적이 2배 빨리 다시 나타나며, 새로 나타나는 적의 15%가 강화(챔피언) 몬스터가 됩니다. 마을은 밝아서 밤 효과가 없습니다.
- **거점 시설**(5단계): 거점 관리인의 "시설 짓기·사용"에서 골드와 건설 재료로 시설을 짓고 1–3단계로 강화합니다. 가방과 창고의 골드·재료를 함께 씁니다.
  - 건설 재료: 천 조각, 목재, 돌 블록, 정제 금속. 오픈월드 던전의 층마다 2–3묶음이 놓이고, 적이 6% 확률로 떨어뜨립니다. 지역마다 많이 나오는 재료가 다릅니다(하수도·감옥은 천·목재, 동굴은 돌, 도시·지옥은 금속).
  - 침대: 다음 날 아침까지 자며 체력 회복(50/75/100%). 대신 배고픔·목마름이 늘고, 3단계는 출혈도 멈춥니다.
  - 모닥불 조리대: 생수 끓이기, 날고기 굽기, 2단계 식량 만들기, 3단계 고기 파이. **생수 끓이기는 이제 조리대가 있어야 합니다.**
  - 의무실: 골드로 모든 부상·출혈 치료(단계별로 100/75/50% 가격).
  - 작물밭: 씨앗을 심으면 900턴 뒤 같은 씨앗 2–3개로 수확합니다(2/4/6칸).
  - 보급 가방: 오픈월드는 보급 가방을 들고 시작합니다. 건설 재료·정수·탄약을 담고 무게 한도를 올려 줍니다(1/2/3단계: 8/13/19칸, 무게 +4/+8/+12). 시설 메뉴에서 강화하고, 거점 상점에서 120골드에 살 수도 있습니다.
  - 대장간: 1단계 저주 해제, 2단계 감정, 3단계 장비 강화(골드 + 정제 금속, 최대 +3).
- **지역 재생성**(6단계): 층을 떠난 지 3일(3600턴)이 지나면 다시 들어갈 때 지형·적·아이템이 새로 만들어집니다. 보스 층은 5일이 지나면 보스와 함께 새로 만들어져 보스를 다시 잡을 수 있습니다(정수 4개). 유품이 있는 층은 회수할 때까지 그대로입니다.
  - **귀환 부적**: 던전 어디서든 마을로 즉시 돌아갑니다(보스 방이 봉쇄된 동안 제외). 거점 관리인에게서 150골드에 삽니다.
  - **생존 기록**: 거점 관리인 메뉴에서 날짜, 영웅 레벨, 사망·처치·보스 수, 열린 지역, 시설과 영구 스탯, 층별 재생성까지 남은 시간을 봅니다.
  - **세이브 목록**: 오픈월드 세이브는 아래쪽에 풀이 자라 있어서 익스트랙션 세이브와 구분됩니다.
- **퀘스트 동료**: 오픈월드에서 원작의 퀘스트를 완료하면 그 NPC가 거점 마을로 옮겨 와 도와줍니다.
  - 유령(하수도): 죽어도 골드를 잃지 않고 체력이 가득 찬 채로 깨어남
  - 마법사(감옥): 하루 한 번 마법봉 전부 충전 + 물약이나 주문서 1개
  - 대장장이(동굴): 하루 한 번 돌 블록 2–4개와 정제 금속 1–2개, 시설·대장간·보급 가방 골드 비용 절반
  - 임프(도시): 거점에서 아이템 판매가 +50%
- **마을 상점가와 훈련장**: 거점 관리인의 "상점가"에서 보급품, 희귀 상품(강화 주문서·힘의 물약은 살 때마다 값이 오름, 마법 지도 주문서, 신성한 영감의 물약), 수상한 상자(하루 3개, 무작위 아이템)를 사고팔 수 있습니다. "훈련장"에서는 골드로 영구 능력치 숙련 경험치를 삽니다(하루 3회, 레벨이 높을수록 비쌈).
- **창고 정리**: 창고는 분류별로 자동 정렬되고, 그때 같은 아이템 묶음(겹칠 수 있는 아이템)은 하나로 합쳐집니다.
- **창고 연동**: 마을에서 구매·시설 건설·훈련에 소지 골드와 창고 골드를 함께 씁니다(소지 골드 먼저). 창고에서 아이템과 골드를 원하는 개수만큼 꺼낼 수 있고, 마을 연금술 작업대에서는 "창고에서" 버튼으로 창고 재료를 바로 넣을 수 있습니다(쓰지 않은 재료는 창고로 돌아감). 창고의 연금 에너지도 마을 작업대에서 쓸 수 있습니다.
- **현상금 게시판**: 거점 관리인 메뉴에서 열린 도시 구역의 표적(HVT) 의뢰를 하나 받으면, 그 구역이 표적·호위병·비밀 금고가 있는 상태로 새로 만들어집니다. 처치하면 즉시 보상(200×구역 번호 골드)과 인식표·전용 장비/금고 열쇠를 얻고, 구역 전체에 경보가 울립니다.
- **연구소**: 지역 지도의 "연구소"에서 키카드 1장(가진 것 먼저, 그다음 창고)을 쓰고 들어갑니다. 들어갈 때마다 새로 만들어지고(유품이 있으면 유지), 귀환 부적이 듣지 않습니다. 엘리베이터로 탈출하면 전리품을 가지고 마을로 돌아오며 엔딩이 뜹니다. 오픈월드에서도 보스·표적·금고에서 키카드가 나옵니다.
- **반지 현자**: 요그 드제바를 쓰러뜨리면 거점 마을에 나타납니다. 반지를 바치면 반지는 사라지고 그 효과가 영구히 적용됩니다(끼고 있는 반지와 중첩). 종류마다 하나씩, 더 강한 반지로 교체 가능, 저주받은 반지는 거절합니다.
- **폐허 도시**: 지역 지도의 "폐허 도시"에서 시가전 도시의 구역으로 갑니다. 같은 캐릭터·스탯·갈증·낮밤이 그대로 이어집니다.
  - 구역 n은 던전 지역 n이 열리면 함께 열립니다(1구역은 처음부터).
  - 성문은 마을로 돌아가는 길이고, 귀환 부적도 쓸 수 있습니다. 죽으면 오픈월드처럼 유품을 남기고 마을에서 깨어납니다.
  - 떠난 지 3일이 지나면 구역 전체(거리와 모든 건물 층)가 새로 바뀝니다. 유품이 있는 구역은 그대로입니다.
  - 던전에서 스탯을 쌓고, 도시에서 희귀한 전리품을 얻는 구조입니다.
- 앞으로의 단계는 [docs/design/open-world-survival.md](docs/design/open-world-survival.md)에 있습니다.

## 시가전 모드

모드 선택의 세 번째 항목입니다. 넓은 폐허 도시의 한가운데서 출발해, 건물을 뒤지고 도시 성벽의 문으로 탈출합니다. 익스트랙션 규칙(탈출하면 창고로, 죽으면 손실)을 따릅니다.

- 매번 새로 만들어지는 72×72칸 도시: 도로망, 건물, 공원, 불탄 차량과 포격 맞은 건물
- 계단은 건물 안에만 있습니다. 위층(최대 3층, 위로 갈수록 전리품이 많고 맨 위층에 보물상자)과 지하층이 있습니다.
- 일부 건물 지하의 지하철 계단으로 더 위험하고 보상이 좋은 다음 구역(총 5구역)으로 갑니다.
- 원작 몬스터에 새 도시형 적(약탈자, 총잡이)이 섞여 나옵니다.
- **오픈월드와 연결**: 오픈월드 캐릭터도 지역 지도의 "폐허 도시"로 같은 도시에 갈 수 있습니다(아래 참고).
- 자세한 내용: [docs/design/urban-warfare.md](docs/design/urban-warfare.md)

## 현상금 토벌 모드 (HVT)

모드 선택의 네 번째 항목입니다. 시가전 도시를 그대로 쓰되, 구역마다 강력한 표적(HVT)이 호위병과 함께 숨어 있습니다.

- 구역에 도착하면 대략적인 위치 힌트만 줍니다. 예: "북동쪽 무기고에서 총성이 울립니다."
- 표적 3종: 군벌 카엘(사격·수류탄), 저주술사 모로우(암흑 화살·마력 폭발), 도살자 그린트(돌진·화염병, 다치면 빨라짐)
- 전술 AI: 발견하면 호위병을 부르고, 몇 번 쏜 뒤 사선 밖으로 숨었다가 다시 나오고, 2턴 뒤 터지는 광역 공격을 던집니다(터질 칸이 표시됨). 체력이 35% 아래로 떨어지면 연막을 치고 도주해 치료합니다(최대 2번).
- 처치 보상: 인식표(팔면 구역 수준의 현상금), 희귀 전리품 1개, 그리고 전용 장비(지휘관의 카빈, 저주의 지팡이, 도살자의 식칼) 또는 구역 비밀 금고의 열쇠 중 하나. 금고에는 골드와 희귀 전리품 2개가 있습니다.
- 처치하는 순간 구역 전체에 경보: 모든 적이 몰려오고, 성문 근처에 증원 병력이 나타나며, 구역을 떠날 때까지 10턴마다 다시 위치가 알려집니다.
- 그 밖에는 시가전 규칙(창고, 성문 탈출, 지하철 구역)을 따릅니다.
- 자세한 내용: [docs/design/hvt-bounty.md](docs/design/hvt-bounty.md)

## 연구소 모드 (최종 목적지)

모드 선택의 다섯 번째 항목입니다. 들어갈 때 창고의 **연구소 키카드** 1장을 씁니다(모드 선택 창에 보유 키카드와 탈출 횟수가 나옵니다).

- **키카드 얻는 곳**(익스트랙션 계열 모드에서만, 가진 채 탈출해야 창고에 남음): DM-300 20%, 드워프 왕 40%, 요그 드제바 100%, 현상금 표적 구역당 10%, 도시 비밀 금고 35%, 3구역부터의 건물 맨 위층 보물상자 4%
- 영웅은 **12레벨**로 시작합니다. 시작 방에서는 발전기를 건드리기 전까지 창고를 쓸 수 있습니다.
- 4×4 방으로 이뤄진 연구 시설(64×64). 적은 **정예 용병**(중무장 원거리)과 **경비 골렘**뿐이고, 30%는 챔피언 특성이 붙습니다.
- 환경 페널티: 허기 2배, 바닥의 가스 배출구에서 주기적으로 독가스
- 탈출 엘리베이터는 전력이 없습니다. 맵 곳곳의 **발전기 3대**를 켜면(켤 때마다 소음과 증원 2명) 엘리베이터 옆 **비상 레버**를 당길 수 있습니다.
- 레버를 당기면 경보가 울리고 정예 증원군 7명이 나타나(절반은 엘리베이터 앞) 탈출할 때까지 8턴마다 위치가 알려집니다.
- 엘리베이터로 탈출하면 전리품이 창고로 가고, **최종 목적지** 엔딩과 함께 탈출 횟수가 기록됩니다.
- 자세한 내용: [docs/design/the-lab.md](docs/design/the-lab.md)

## 고유 무기와 보스 전리품

보스의 전리품 2개를 연금술 솥에 넣으면 그 보스의 고유 무기가 됩니다. 두 모드 모두에서 만들 수 있습니다.

| 보스 | 전리품 | 고유 무기 | 효과 |
|---|---|---|---|
| 구 | 구의 점액 (원작) | 점액 칼날 (2티어) | 33% 확률로 산성 점액(지속 피해) |
| 텐구 | 텐구의 깃털 (새로 드랍) | 텐구의 발톱 (3티어) | 공격 속도 1.5배, 15% 확률로 3턴 실명 |
| DM-300 | 금속 파편 (원작) | 피스톤 망치 (4티어) | 20% 확률로 보스가 아닌 적 2턴 기절 |
| 드워프 왕 | 왕의 인장 (새로 드랍) | 왕의 글레이브 (5티어) | 2칸 공격, 준 피해의 15% 흡혈 |

- 텐구와 드워프 왕은 이제 구·DM-300처럼 전리품을 2–4개 떨어뜨립니다.
- 효과 확률은 강화할수록 단계당 2%씩 오릅니다. 수치는 `efpd/uniques/UniqueWeapon.java`에 있습니다.
- 창고는 자동으로 분류별로 정렬됩니다(고유 무기, 총기, 근접 무기 순, 같은 분류에서는 높은 티어 먼저).

## 총기

- 티어마다 3종씩 총 15종의 총기를 근접 무기 드랍 풀에 추가했습니다. 바닥, 상점, 퀘스트 보상, 변형 주문서에서 나옵니다.
- 장착한 뒤 **사격**하면 탄창에서 1발을 쓰고, **재장전**하면 가방의 탄약(권총탄 / 소총탄 / 산탄)을 탄창에 채웁니다.
- 사격으로 조준한 상태에서 **자기 자신을 누르면 재장전**합니다. 탄창이 비어 있어도 조준할 수 있습니다.
- 총소리가 나면 주변의 적이 몰려옵니다. 산탄총은 가까이서 강하고, 저격총은 멀리서 정확합니다.
- 계층별 티어 확률, 총기 능력치, 탄약 드랍은 [docs/design/item-tiers.md](docs/design/item-tiers.md)에 정리했습니다.

## 개발자 도구

- 개발 빌드(`./gradlew desktop:debug`, 버전에 INDEV 표시)에서만, 게임 중 우측 상단 메뉴에 **개발자 도구**가 나옵니다.
- 디버그 항목: 완전 회복(부상·출혈 포함), 즉사(사망 처리 테스트용), 숙련도 +100(모든 영구 스탯, 오픈월드 전용), 탈수 상태 만들기, 월드 시간 300턴 넘기기, 부상 입기, 퀘스트 NPC 모두 합류.
- 강장제는 강화 단계 값이 등급이 됩니다(0이면 1등급).
- 첫 화면: 현재 위치와 **한 층 위로 / 한 층 아래로** 버튼, **층 번호로 이동**(던전 1–26층). 도시에서는 이전·다음 구역, 거점에서 아래로 가면 1층, 오픈월드 1층에서 위로 가면 거점으로 갑니다. 연구소에서는 막힙니다.
- 그 아래 목록에서 재화, 디버그, 아이템 카테고리(근접 무기 티어별, 총기, 탄약, 방어구, 완드, 반지, 물약 등)를 골라 카테고리별 페이지로 들어갑니다.
- 아이템 페이지 상단에서 강화 단계(0–30)와 개수(1–999)를 정하고(숫자를 누르면 직접 입력), 아래 목록에서 아이템 이름을 누르면 지급됩니다.
- 목록은 게임의 아이템 표에서 자동으로 만들어지므로, 새 아이템을 드랍 풀에 넣으면 따로 등록하지 않아도 나타납니다.

## 모바일(안드로이드) 설치와 릴리즈

- [Releases](../../releases)에서 최신 `EscapeFromPixelDungeon-<버전>.apk`를 받아 설치합니다(안드로이드 5.0 이상, "출처를 알 수 없는 앱" 허용 필요).
- `-devtools.apk`는 개발자 도구가 켜진 테스트용이며, 별도 앱으로 설치됩니다.
- 새 버전 만들기: `build.gradle`의 `appVersionCode`·`appVersionName`과 `docs/release-notes.md`(맨 아래 `internal version number` 포함)를 고쳐서 푸시하면, GitHub Actions(`.github/workflows/android-release.yml`)가 `v<appVersionName>` 릴리즈를 만들어 APK를 올립니다. Actions 탭에서 수동으로 실행할 수도 있습니다. 게임 안의 업데이트 알림도 이 릴리즈를 봅니다.
- 서명: 저장소 시크릿 `EFPD_KEYSTORE_B64`(키스토어 base64), `EFPD_KEYSTORE_PASSWORD`, `EFPD_KEY_ALIAS`, `EFPD_KEY_PASSWORD`가 있으면 그 키로 서명합니다. 없으면 저장소에 들어 있는 `android/efpd-debug.keystore`(비밀번호가 공개된 디버그용 키)로 서명합니다. 서명 키를 바꾸면 기존 앱 위에 업데이트할 수 없어 삭제 후 재설치(세이브 삭제)가 필요하니, 개인 키는 정식 배포 전에 정하는 것이 좋습니다.

- 업데이트 내역: 게임 안 "변경사항" 화면의 첫 탭(Escape from PD)은 `ui/changelist/EFPD_Changes.java`에서 버전별로 관리합니다. 새 버전을 릴리즈할 때마다 맨 위에 섹션을 추가합니다(`docs/release-notes.md`와 함께).

## 빌드 (데스크톱)

```bash
# Android SDK 없이 데스크톱만 빌드/실행
./gradlew desktop:debug -PdesktopOnly     # 실행
./gradlew desktop:release -PdesktopOnly   # 실행 가능한 jar
```

`-PdesktopOnly`를 빼면 원래처럼 android/ios 모듈도 포함됩니다 (Android SDK 필요).
